
Edge AI : AI models that run on edge computers。

## 一、先建立直觉：端侧 Agent 到底是什么

普通大模型应用通常是：你发一句话 → 传到云服务器 → 巨型模型思考 → 返回答案。

端侧 Agent 把「模型思考」和「执行动作」尽量放在你自己的设备里：手机、PC、平板、车机、智能音箱、工控盒都算。

一个端侧 Agent 最小组成就四件事：

1. **感知**：读文本、文件、截图、麦克风、传感器数据
2. **决策**：本地小模型判断「用户要什么、该调哪个工具、分几步做」
3. **执行**：调本地工具——读文件、写日历、发通知、搜本地知识库、调系统接口
4. **记忆**：把历史对话、用户偏好、文档片段存在本机，下次能召回 

类比：云端 Agent 像打电话问总部参谋；端侧 Agent 像你手机里雇了个不会把资料寄出去的私人助理，断网也能干一部分活，复杂事再替你请示总部。

## 二、端侧 vs 云端：什么时候用端侧

不是「端侧替代云端」，而是按任务分流。 

|维度|端侧 Agent|云端 Agent|
|---|---|---|
|模型大小|1B–7B 为主，量化后跑；PC 可上更大|几十B到几百B、甚至更大|
|延迟|本地推理，毫秒~亚秒级|受网络往返+队列影响，常几百ms~数秒|
|隐私|原始数据可不出机|需上传提示词/文件/截图|
|离线|可完全离线保底|断网即废|
|成本|一次性部署，边际成本低|按 token/调用持续付费|
|能力上限|摘要、分类、意图、简单多步还行；复杂推理弱|强推理、长上下文、重多模态、代码全栈更好|
|典型硬件|手机NPU/CPU、Mac Apple Silicon、PC独显/核显、ARM盒子|云GPU集群|
